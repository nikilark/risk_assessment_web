Цей документ описує реалізовані формули, а не затверджує їхню медичну застосовність. Джерело: `web/src/domain/risk.ts`, `comparison.ts`, `results.ts`. Розрахунки виконуються окремо для кожного об'єкта, речовини та року; роки не сумуються. Концентрації і референтні значення мають однакові одиниці та період усереднення.

# Неканцерогенний ризик

Для кожної речовини HQ = C / RfC, де C — концентрація, RfC — хронічна або гостра референтна концентрація. Наприклад, 0.099 / 0.04 = 2.475. Речовини з RfC ≤ 0 не допускаються до відповідного результату; допоміжна функція повертає 0 для RfC ≤ 0.

Сумарний HI = Σ HQᵢ. Для органа HI органа = Σ HQᵢ лише тих речовин, що впливають на орган. Якщо відсутня концентрація хоча б однієї потрібної обраної речовини, сума показується як «—».

Шкала HQ/HI: мінімальний < 0.1; низький 0.1 ≤ x < 1; середній 1 ≤ x < 5; високий 5 ≤ x < 10; критичний x ≥ 10. Це шкала застосунку; вона не тотожна таблиці МОЗ 2007.

# Канцерогенний ризик

Для вікової групи ADD = C × IR × 70 × 350 / (BW × 70 × 365), де IR — вдихання м³/добу, BW — маса кг. Множники 70 скорочуються. У довічному сценарії:

LADD = [6 × ADD(4, 15) + 12 × ADD(20, 42) + 52 × ADD(22, 70)] / 70.

Три пари (IR, BW) відповідають віку 0–6, 6–18 і 18–70 років. Частота впливу 350 днів/рік, тривалість 70 років. Значення C — мг/м³; LADD — мг/(кг·добу).

У режимі, названому гострим: LADD = C × 20 × 70 × 350 / (60 × 70 × 365). У ньому також використовується довічна тривалість; застосовність назви та сценарію не підтверджена.

ICR = LADD × SFi; PCR = ICR × N; PCRa = PCR / 70; PCR на 10000 = ICR × 10000; PCRa на 10000 = ICR / 70 × 10000. N — населення, SFi — інгаляційний фактор нахилу в (мг/(кг·добу))⁻¹. Сумарний канцерогенний ризик = Σ ICRᵢ для одного об'єкта і року. Значення SFi ≤ 0 виключають речовину з цієї моделі.

Шкала ICR: мінімальний < 10⁻⁶; низький 10⁻⁶ ≤ x < 10⁻⁴; середній 10⁻⁴ ≤ x < 10⁻³; високий x ≥ 10⁻³.

# Додаткова смертність від частинок

PM10: C₁₀ = C. TSP: C₁₀ = 0.6 × C. PM2.5 не входить у цю модель; вона доступна для HQ/HI. Перетворення TSP виконується один раз і лише для моделі смертності.

Nₛ = max(1, N); IRM = D × 0.005 / (365 × Nₛ); SF = IRM × 70 × 365; AM = C₁₀ × SF × Nₛ; AM на 10000 = AM / Nₛ × 10000. D — річні випадки смерті. Використовується та сама п'ятирівнева шкала, що для HQ. Приклад: C(TSP)=0.1, D=100, N=50000: C₁₀=0.06, AM=2.1, AM на 10000=0.42.

Модель зберігає числовий підхід диплома; масштаб одиниць концентрації, фактор відповіді та шкала смертності потребують окремої перевірки. Значення N=0 замінюється одиницею всередині функції; це не підтверджує правильність оцінки за невідомого населення.

# Параметри й обмеження

Параметри RfC та SFi залежать від речовини; нуль означає, що показник не заданий, а не відсутність ризику. Для CO хронічне значення 3 мг/м³ є еквівалентом ГДК, а не встановленою EPA RfC. TSP гостре значення 0.3 мг/м³ лишається неперевіреним. Каталог частково звірено з МОЗ №184/2007 і OEHHA: докладніше у `manual/reference_review_2026-10-27.md`.

Одна введена концентрація використовується для гострого і хронічного режимів. Якщо її одиниці або період усереднення невідомі, інтерпретація результатів не підтверджена. Населення і річна смертність у проєкті є спільними для всіх років.
